## State model (controlled/uncontrolled, defaults, transitions)

- Controlled multiple mode tolerates `value={null}` (documented as a legitimate loading-time state); the items then render with `aria-selected="false"` and clicking item "one" reports `onValueChange(['one'], <event details>)` `packages/react/src/select/item/SelectItem.test.tsx:25-54`.
- Controlled selection callback signature: first argument is the value (`'two'` as a string in single mode `packages/react/src/select/item/SelectItem.test.tsx:411`, `['one']` as an array in multiple mode `packages/react/src/select/item/SelectItem.test.tsx:53`); second argument is an opaque event-details object (`expect.anything()`) `packages/react/src/select/item/SelectItem.test.tsx:53`, `packages/react/src/select/item/SelectItem.test.tsx:411`.
- Uncontrolled selection via `defaultValue="b"`: the item's `data-selected` attribute survives reordering and late insertion of grouped items (prepend "a", reverse order twice; option "b" keeps `data-selected` after each change) `packages/react/src/select/item/SelectItem.test.tsx:56-118`.
- Uncontrolled multiple selection via `defaultValue={['a']}`: the item starts selected and its ItemIndicator renders `data-selected`; clicking the selected option toggles it off (indicator loses `data-selected`) `packages/react/src/select/item-indicator/SelectItemIndicator.test.tsx:27`, `packages/react/src/select/item-indicator/SelectItemIndicator.test.tsx:45-52`.
- `defaultOpen` renders the popup already open at mount (items are queried without opening interaction) `packages/react/src/select/item/SelectItem.test.tsx:333`, `packages/react/src/select/item/SelectItem.test.tsx:477`.
- Clicking an enabled item in single mode commits the value into `Select.Value` text and closes the popup (`value.textContent` becomes `'one'`; positioner becomes not visible) `packages/react/src/select/item/SelectItem.test.tsx:120-150`.
- Reopening the popup focuses the previously selected item and marks it `data-selected` (option "three"/"a" respectively) `packages/react/src/select/item/SelectItem.test.tsx:444-471`, `packages/react/src/select/item/SelectItem.test.tsx:1060-1086`.
- With no selection, `Select.Value` renders its `placeholder` text (`'Select font'`) and stays at the placeholder when a commit is blocked `packages/react/src/select/item/SelectItem.test.tsx:552`, `packages/react/src/select/item/SelectItem.test.tsx:568-570`, `packages/react/src/select/item/SelectItem.test.tsx:740`, `packages/react/src/select/item/SelectItem.test.tsx:1026`.
- `highlightItemOnHover={false}` suppresses the `data-highlighted` attribute on hover/move, and unhighlighted items still commit on real mouse clicks (see Events and Edge cases) `packages/react/src/select/item/SelectItem.test.tsx:350`, `packages/react/src/select/item/SelectItem.test.tsx:862`.
- ItemIndicator transition state: after a kept-mounted indicator is deselected, it must end with neither `data-selected` nor `data-ending-style` (the exit-transition style hook clears once deselection finishes) `packages/react/src/select/item-indicator/SelectItemIndicator.test.tsx:50-58`.

## Keyboard interactions

- `ArrowDown` moves item focus/highlight to the next item: after opening, focus starts on item "one"; each `ArrowDown` moves focus to "two" then "three" (jsdom-only test) `packages/react/src/select/item/SelectItem.test.tsx:152-189`.
- `Enter` commits the item at the keyboard position: open, two `ArrowDown` presses, then `Enter` sets the value to "two" (jsdom-only test) `packages/react/src/select/item/SelectItem.test.tsx:191-218`.
- Typeahead: with the popup open and the first item focused, typing the string `'item t '` (ending with Space) moves focus to the item labeled "Item Two" (browser-only test, skipped in jsdom) `packages/react/src/select/item/SelectItem.test.tsx:473-510`.
- After a typeahead sequence ending with Space, a pointer click on the focused item still selects it (value becomes "two") — this is browser-only `packages/react/src/select/item/SelectItem.test.tsx:504-508`.
- `ArrowDown` also moves the `data-highlighted` style hook: initially option "a" (the `defaultValue`) is `data-highlighted=""`; after `ArrowDown`, "a" loses it and "b" gains it `packages/react/src/select/item/SelectItem.test.tsx:1032-1058`.

## Events (names, payload shape, bubbling, preventDefault semantics)

- `onValueChange(value, eventDetails)` on the Root: in single mode the first argument is the item's value string (`'two'`) and the callback is invoked exactly once per commit; in multiple mode it is an array (`['one']`); the second argument is an opaque details object (always matched with `expect.anything()`) `packages/react/src/select/item/SelectItem.test.tsx:411`, `packages/react/src/select/item/SelectItem.test.tsx:53`.
- Item `onClick` fires exactly once for a regular click on an enabled item `packages/react/src/select/item/SelectItem.test.tsx:300-329`.
- Item `onClick` also fires exactly once for a drag-to-select commit (mousedown on trigger, pointer moves, mouseup on item) `packages/react/src/select/item/SelectItem.test.tsx:607-651`.
- Item `onClick` is NOT called when the item is `disabled` (direct click) or when the root is `disabled` `packages/react/src/select/item/SelectItem.test.tsx:296`, `packages/react/src/select/item/SelectItem.test.tsx:693`.
- The click event object passed to item `onClick` exposes `preventBaseUIHandler()`; calling it suppresses the selection commit and keeps the popup open (value stays at placeholder; `listbox` still present) while the user handler itself still runs (called once) `packages/react/src/select/item/SelectItem.test.tsx:985-1028`.
- Hover events: `pointerEnter` (pointerType `mouse`) plus `mouseMove` on an item sets `data-highlighted` when hover highlighting is enabled (default) `packages/react/src/select/item/SelectItem.test.tsx:397-402`.
- Mouse commit sequence: a full physical click (`pointerDown`+`mouseDown`, `pointerUp`+`mouseUp`, `click` with `detail: 1`) commits an unhighlighted item when `highlightItemOnHover={false}` `packages/react/src/select/item/SelectItem.test.tsx:331-360`.
- Synthetic clicks with `detail: 0` ("generic virtual click") on an unhighlighted item do NOT commit `packages/react/src/select/item/SelectItem.test.tsx:417-442`.
- The click that opened the popup does not commit even if its mouseup/click lands on an item: `pointerDown`+`mouseDown` on trigger, then `mouseUp`+`click(detail: 1)` on the option leaves the value at the placeholder `packages/react/src/select/item/SelectItem.test.tsx:954-983`.
- Event bubbling from item click to ancestor handlers — UNVERIFIED — inferred from `packages/react/src/select/item/SelectItem.test.tsx:300-329` (only the item's own `onClick` is observed), no test asserts bubbling behavior.

## Edge cases (rapid interactions, unmount, nesting)

Quick-selection suite (fake timers, jsdom-only; uses `createRenderer({ clockOptions: { shouldAdvanceTime: true } })`, `clock.withFakeTimers()`, `clock.tickAsync(ms)`) `packages/react/src/select/item/SelectItem.test.tsx:512-519`:

- Quick mouseup over an unselected option shortly after opening (open via `mouseDown` on trigger, `mouseMove` over the option, `tickAsync(250)`, `mouseUp`) does NOT select when a placeholder is shown (the "no null item" case) — the value stays at the placeholder `packages/react/src/select/item/SelectItem.test.tsx:521-571`.
- Same delay gate applies with `alignItemWithTrigger` and an existing selection: mouseup over "two" at ~250ms leaves value "one" `packages/react/src/select/item/SelectItem.test.tsx:573-605`.
- Drag-to-select: with real `pointerMove` traffic (`buttons: 1`, `movementY: 2`) over an item, selection works even before the opening delay elapses (`tickAsync(100)` then `mouseUp` → value commits and item `onClick` fires once) `packages/react/src/select/item/SelectItem.test.tsx:607-651`.
- Drag-to-select over a disabled item neither synthesizes its `onClick` nor commits a selection (`onValueChange` not called; value stays placeholder) `packages/react/src/select/item/SelectItem.test.tsx:653-694`, `packages/react/src/select/item/SelectItem.test.tsx:696-741`.
- Touch: a `pointerEnter` with `pointerType: 'touch'` followed by `mouseUp` (after `tickAsync(500)`) does not commit — a finger-drag/scroll over items must not pick the release target `packages/react/src/select/item/SelectItem.test.tsx:743-781`.
- Movement accumulates across items: `movementY: 4` over "two" plus `movementY: 4` over "three" then `mouseUp` on "three" commits "three" `packages/react/src/select/item/SelectItem.test.tsx:783-829`.
- Drag-to-select works with hover highlighting disabled (`highlightItemOnHover={false}`, `movementY: 8`, item never `data-highlighted`, `tickAsync(500)`, `mouseUp` → commits) `packages/react/src/select/item/SelectItem.test.tsx:831-870`.
- Small pointer movement is gated: total `movementY: 2` with `tickAsync(100)` before `mouseUp` does NOT select (with `alignItemWithTrigger`); the same small movement DOES select after `tickAsync(500)` — the movement threshold applies only during the opening delay window `packages/react/src/select/item/SelectItem.test.tsx:872-913`, `packages/react/src/select/item/SelectItem.test.tsx:915-952`.
- Typeahead-then-click: after a typeahead sequence ending with Space, a pointer click still selects (browser-only) `packages/react/src/select/item/SelectItem.test.tsx:473-510`.
- Grouped item reorder/insertion: prepending and reversing items keeps the selection attached to the correct option (`data-selected` follows value "b") `packages/react/src/select/item/SelectItem.test.tsx:56-118`.
- Disabled inheritance: when the root is `disabled`, items render `data-disabled`, ignore clicks (no `onClick`, no commit) `packages/react/src/select/item/SelectItem.test.tsx:271-298`.
- Rapid highlight commit: hover-highlighted item commits exactly one `onValueChange` on click and the value text updates `packages/react/src/select/item/SelectItem.test.tsx:395-414`.
- Unmount behavior (popup unmount, indicator unmount without `keepMounted`) — UNVERIFIED — inferred from `packages/react/src/select/item-indicator/SelectItemIndicator.test.tsx:36`, no unmount test exists in these files.
- Nested Selects — UNVERIFIED — inferred from `packages/react/src/select/item/SelectItem.test.tsx:74-87` (only grouping nesting is exercised), no nested-Select test exists in these files.
