# Combobox — items & item parts (behavior spec)

Scope: `Combobox.createItems` collections, `Combobox.Item`, `Combobox.ItemContext`, `Combobox.ItemIndicator`, `Combobox.Collection`, mined from their test files only.

## Public API surface (props, parts, subcomponents)

- `Combobox.createItems(data, { getValue, getLabel })` builds a collection whose items derive a primitive selection value via `getValue` and a display label via `getLabel` `packages/react/src/combobox/items/createItems.test.tsx:55-58`.
- A collection can be created once and shared by multiple roots and renders, the way a module-scope collection is `packages/react/src/combobox/items/createItems.test.tsx:65-69`, `packages/react/src/combobox/items/createItems.test.tsx:1464-1493`.
- Passing a plain object (not a collection) as `items` makes the root throw an error matching /not a collection/ `packages/react/src/combobox/items/createItems.test.tsx:75-85`.
- `createItems` accepts `undefined` data and treats it as the absence of items rather than an empty list: externally supplied `filteredItems` still render `packages/react/src/combobox/items/createItems.test.tsx:87-109`.
- Grouped data is supported: an array-valued `items` field on a source record marks it a group `packages/react/src/combobox/items/createItems.test.tsx:1896-1899`; only a real array marks a group — `items: undefined` and `items: 3` remain item data `packages/react/src/combobox/items/createItems.test.tsx:427-462`; an array-valued `items` field typed `unknown` is rejected at compile time (`@ts-expect-error`) `packages/react/src/combobox/items/createItems.test.tsx:464-484`.
- `Combobox.Group` takes an `items` prop with the group's leaf items and renders `Combobox.GroupLabel` plus a `Combobox.Collection` render-prop over the leaves `packages/react/src/combobox/items/createItems.test.tsx:1909-1921`.
- `Combobox.Item` props exercised: `value` (primitive) `packages/react/src/combobox/item/ComboboxItem.test.tsx:26-27`, `disabled` `packages/react/src/combobox/item/ComboboxItem.test.tsx:145-147`, `index` `packages/react/src/combobox/item/ComboboxItem.test.tsx:579`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:689`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:720`, `onClick` `packages/react/src/combobox/item/ComboboxItem.test.tsx:54`, and `render` (e.g. anchor elements) `packages/react/src/combobox/item/ComboboxItem.test.tsx:348`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:648`.
- An `Item` whose value is missing from the filtered set (here rendered without `value`) still renders its content but is not registered `packages/react/src/combobox/item/ComboboxItem.test.tsx:548-572`.
- `Combobox.ItemIndicator` accepts `keepMounted` and is placed inside item content `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:9-18`, `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:28-31`.
- `Combobox.Collection` renders items through a render-prop callback: at the top of `List` it iterates the filtered items `packages/react/src/combobox/collection/ComboboxCollection.test.tsx:17-23`; inside a `Group` it iterates that group's items `packages/react/src/combobox/items/createItems.test.tsx:1913-1919`.
- `Combobox.List` accepts a render-function child receiving each source item (leaf) or group `packages/react/src/combobox/items/createItems.test.tsx:99-104`, `packages/react/src/combobox/items/createItems.test.tsx:1910-1921`.
- `Combobox.Value` supports a `placeholder` `packages/react/src/combobox/items/createItems.test.tsx:1057` and a render-prop child receiving the raw selected value `packages/react/src/combobox/items/createItems.test.tsx:1176-1194`.
- Root props exercised by these files: `items`/`defaultOpen` `packages/react/src/combobox/items/createItems.test.tsx:119`, `filteredItems` `packages/react/src/combobox/items/createItems.test.tsx:96`, `packages/react/src/combobox/items/createItems.test.tsx:292`, `value`/`onValueChange` `packages/react/src/combobox/items/createItems.test.tsx:179`, `multiple` `packages/react/src/combobox/items/createItems.test.tsx:1078`, `name` `packages/react/src/combobox/items/createItems.test.tsx:1111`, `itemToStringLabel` `packages/react/src/combobox/items/createItems.test.tsx:684`, `itemToStringValue` `packages/react/src/combobox/items/createItems.test.tsx:1139`, `isItemEqualToValue` `packages/react/src/combobox/items/createItems.test.tsx:827`, `filter` `packages/react/src/combobox/items/createItems.test.tsx:855`, `limit` `packages/react/src/combobox/items/createItems.test.tsx:1792`, `locale` `packages/react/src/combobox/items/createItems.test.tsx:746`, `virtualized` `packages/react/src/combobox/items/createItems.test.tsx:1591`, `inline`/`open` `packages/react/src/combobox/items/createItems.test.tsx:615`, `onItemHighlighted` `packages/react/src/combobox/items/createItems.test.tsx:1554`, plus `openOnInputClick` `packages/react/src/combobox/item/ComboboxItem.test.tsx:47`, `disabled` `packages/react/src/combobox/item/ComboboxItem.test.tsx:166`, and `autoHighlight` `packages/react/src/combobox/item/ComboboxItem.test.tsx:682`.

## State model (controlled/uncontrolled, defaults, transitions)

- Selecting an item commits the derived value, not the label: clicking "Bob" fires `onValueChange(2)` and the input displays the label "Bob" while closed `packages/react/src/combobox/items/createItems.test.tsx:132-138`; grouped collections behave identically `packages/react/src/combobox/items/createItems.test.tsx:1927-1936`, as do virtualized roots and explicitly valued items `packages/react/src/combobox/items/createItems.test.tsx:1585-1609`, `packages/react/src/combobox/items/createItems.test.tsx:1756-1780`.
- Uncontrolled usage: `defaultValue` resolves its label while closed `packages/react/src/combobox/items/createItems.test.tsx:502-522` and highlights that item when opened `packages/react/src/combobox/items/createItems.test.tsx:579-609` or on inline mount `packages/react/src/combobox/items/createItems.test.tsx:611-635`. Controlled `value` drives both the label `packages/react/src/combobox/items/createItems.test.tsx:179-183` and item `aria-selected` `packages/react/src/combobox/items/createItems.test.tsx:218-224`.
- Multiple mode holds an array: clicks append/remove in selection order — `[2]` → `[2, 3]` → `[3]` — and `aria-selected` mirrors membership `packages/react/src/combobox/items/createItems.test.tsx:1072-1106`; the popup stays open while toggling `packages/react/src/combobox/item/ComboboxItem.test.tsx:280-310`.
- Label degradation: when a selected value cannot be resolved from collection data, the raw value is displayed — `user-3` after API results are cleared `packages/react/src/combobox/items/createItems.test.tsx:338-386`, `3` while data is undefined or shrinks past the selection `packages/react/src/combobox/items/createItems.test.tsx:553-577`, `99` for IDs absent from data `packages/react/src/combobox/items/createItems.test.tsx:953-969`, and per-value degradation in multiple mode (`user-1, Bob`) `packages/react/src/combobox/items/createItems.test.tsx:1495-1527`.
- `itemToStringLabel` covers only values the collection cannot resolve; collection-owned items keep their `getLabel` label (value 2 → "Bob" `packages/react/src/combobox/items/createItems.test.tsx:705-735`, value 99 → "Archived user" `packages/react/src/combobox/items/createItems.test.tsx:705-735`).
- Labels are reactive: a stable accessor returning a new result updates the input and `Value` labels when props change (locale switch → "Alicia") `packages/react/src/combobox/items/createItems.test.tsx:767-814`; an externally filtered window labels the selection in the same commit the item first appears `packages/react/src/combobox/items/createItems.test.tsx:1213-1241`, relabels when a later window carries a renamed item ("Ann" → "Anna") `packages/react/src/combobox/items/createItems.test.tsx:1435-1462`, and window removal degrades the label `packages/react/src/combobox/items/createItems.test.tsx:1395-1433`.
- Undefined data renders zero options and fills in once loaded `packages/react/src/combobox/items/createItems.test.tsx:524-551`; options are absent until an async request resolves `packages/react/src/combobox/items/createItems.test.tsx:209-218`.
- Highlight state follows the selected value on open `packages/react/src/combobox/items/createItems.test.tsx:579-609`, including opening a reordered external window at the selected value in rendered-list coordinates `packages/react/src/combobox/items/createItems.test.tsx:1543-1583`.
- `ItemIndicator keepMounted` reflects selection transitions: `data-selected` present while its item is selected, removed when deselected `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:20-45`.
- Form serialization: hidden inputs named via `name` carry `String(derivedValue)` in single `packages/react/src/combobox/items/createItems.test.tsx:1120-1129` and multiple mode `packages/react/src/combobox/items/createItems.test.tsx:1108-1118`, or the `itemToStringValue` output `packages/react/src/combobox/items/createItems.test.tsx:1131-1147`.
- No selection renders an empty `Value` (null is not stringified) `packages/react/src/combobox/items/createItems.test.tsx:1029-1044`, shows the `placeholder`, and a source field literally named `value` is not treated as selection state `packages/react/src/combobox/items/createItems.test.tsx:1046-1070`.
- `Combobox.Value` joins all selected labels in multiple mode ("Alice, Bob") `packages/react/src/combobox/items/createItems.test.tsx:1196-1211`.

## Keyboard interactions

- ArrowDown highlights the first item; Enter selects the highlighted item and closes the popup in single mode `packages/react/src/combobox/item/ComboboxItem.test.tsx:192-217`.
- Enter selection commits the derived value (`onValueChange(1)`) `packages/react/src/combobox/items/createItems.test.tsx:1684-1711`.
- Enter selection dispatches through the item's own `onClick` handler ("via root interaction") `packages/react/src/combobox/item/ComboboxItem.test.tsx:74-103`.
- After filtering, ArrowDown+Enter selects the first filtered item — including virtualized lists whose indexes must be re-resolved against the filtered set ("four", formerly index 3) `packages/react/src/combobox/item/ComboboxItem.test.tsx:456-474`, and explicitly indexed virtualized items ("two") `packages/react/src/combobox/item/ComboboxItem.test.tsx:575-613`.
- Closed-trigger typeahead: with the popup closed, a character key on the focused trigger selects the item whose derived label matches ("z" → "Zebra") without opening the listbox `packages/react/src/combobox/items/createItems.test.tsx:989-1027`.
- In externally virtualized collections, ArrowDown highlights by derived value (`onItemHighlighted(2)`) and Enter selects it (`onValueChange(2)`) `packages/react/src/combobox/items/createItems.test.tsx:1713-1754`.

## Focus management

- `mousedown` on an item is preventDefault-ed so pointer selection does not steal focus from the input `packages/react/src/combobox/item/ComboboxItem.test.tsx:251-278`.
- Selecting an item with touch keeps focus on the input (browser-only test) `packages/react/src/combobox/item/ComboboxItem.test.tsx:219-249`.
- Hovering an item moves the highlight to it and off the previously highlighted item, including explicitly indexed items in non-virtualized lists (regression for mui/base-ui#4657) `packages/react/src/combobox/item/ComboboxItem.test.tsx:674-714`.
- Hovering an unregistered item neither highlights it nor sets `aria-activedescendant` on the input `packages/react/src/combobox/item/ComboboxItem.test.tsx:548-572`.
- The input remains the focus owner while the highlight moves: inline-open roots set `aria-activedescendant` on the input to the highlighted item's id `packages/react/src/combobox/items/createItems.test.tsx:611-635`.

## Accessibility (roles, aria-*, id linking)

- Items expose `role="option"` and the list `role="listbox"` `packages/react/src/combobox/item/ComboboxItem.test.tsx:36`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:40`.
- `aria-selected="true"`/`"false"` reflects selection, including restored on reopen `packages/react/src/combobox/item/ComboboxItem.test.tsx:312-335`, `packages/react/src/combobox/items/createItems.test.tsx:241-244`, and under controlled/async data `packages/react/src/combobox/items/createItems.test.tsx:218-224`.
- Item content supplies the accessible name (options are queried by name, e.g. derived label "Bob" or rich content matched by /Bob/) `packages/react/src/combobox/items/createItems.test.tsx:134`, `packages/react/src/combobox/items/createItems.test.tsx:218-224`.
- Highlighted items carry `data-highlighted`; the input's `aria-activedescendant` links to the highlighted item's `id` `packages/react/src/combobox/items/createItems.test.tsx:606-608`, `packages/react/src/combobox/items/createItems.test.tsx:633-634`.
- Registered items get `id` attributes; unregistered items (missing from filtered values, or `index={-1}`) get no `id` `packages/react/src/combobox/item/ComboboxItem.test.tsx:548-572`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:716-728`.
- Disabled items carry `data-disabled`, whether disabled themselves or inherited from a disabled root `packages/react/src/combobox/item/ComboboxItem.test.tsx:145-147`, `packages/react/src/combobox/item/ComboboxItem.test.tsx:162-190`.
- `ItemIndicator` exposes `data-selected` while its item is selected `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:40-44`.
- Item parts used outside `<Combobox.Item>` throw: "Base UI: ComboboxItemContext is missing. ComboboxItem parts must be placed within <Combobox.Item>." `packages/react/src/combobox/item/ComboboxItemContext.test.tsx:17-19`.

## DOM structure & portal behavior

- `Combobox.Item` renders an `HTMLDivElement` (conformance ref check) `packages/react/src/combobox/item/ComboboxItem.test.tsx:11-16`; `Combobox.ItemIndicator` renders a `span` `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:9-18`.
- Items are composed as `Portal > Positioner > Popup > List > Item`; selecting in single mode unmounts the popup (listbox query returns null) `packages/react/src/combobox/item/ComboboxItem.test.tsx:18-41`, `packages/react/src/combobox/items/createItems.test.tsx:233-237`.
- Inline (non-portal) lists are supported and highlight the selected item on mount `packages/react/src/combobox/items/createItems.test.tsx:611-635`.
- Hidden form inputs with the root `name` are rendered for value serialization `packages/react/src/combobox/items/createItems.test.tsx:1108-1118`, `packages/react/src/combobox/items/createItems.test.tsx:1120-1129`.
- Virtualized rendering: `useFilteredItems`-driven items register their DOM nodes into the root's `listRef` at their filtered indexes, leaving empty slots for unrendered indexes ("||three|four|") `packages/react/src/combobox/item/ComboboxItem.test.tsx:492-546`.
- `Combobox.Collection` renders the filtered items via its render prop `packages/react/src/combobox/collection/ComboboxCollection.test.tsx:9-34`, and renders nothing (empty group DOM) when a nested `Group` provides no items `packages/react/src/combobox/collection/ComboboxCollection.test.tsx:36-56`.
- With `Portal keepMounted`, a mounted indicator stays in the DOM and updates its `data-selected` state as selection changes `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:20-45`.

## Events (names, payload shape, bubbling, preventDefault semantics)

- Click on an enabled item selects it: single mode closes the popup `packages/react/src/combobox/item/ComboboxItem.test.tsx:18-41`; multiple mode keeps it open and toggles `aria-selected` `packages/react/src/combobox/item/ComboboxItem.test.tsx:280-310`.
- The item `onClick` prop fires once per selection gesture — pointer click `packages/react/src/combobox/item/ComboboxItem.test.tsx:44-72` and Enter-key selection `packages/react/src/combobox/item/ComboboxItem.test.tsx:74-103`.
- Calling `event.preventBaseUIHandler()` inside item `onClick` cancels Base UI's selection and close: the handler runs, the input stays empty, and the popup remains open `packages/react/src/combobox/item/ComboboxItem.test.tsx:105-133`.
- Disabled items never select and never invoke `onClick`, whether disabled themselves `packages/react/src/combobox/item/ComboboxItem.test.tsx:136-160` or via a disabled root `packages/react/src/combobox/item/ComboboxItem.test.tsx:162-190`.
- `onValueChange` payload is the derived value in single mode `packages/react/src/combobox/items/createItems.test.tsx:132-138` and an array in selection order in multiple mode `packages/react/src/combobox/items/createItems.test.tsx:1072-1106`; selecting an async-loaded item passes its derived ID to app callbacks `packages/react/src/combobox/items/createItems.test.tsx:233-237`.
- `onItemHighlighted` receives the derived value of the highlighted item `packages/react/src/combobox/items/createItems.test.tsx:1543-1583`, `packages/react/src/combobox/items/createItems.test.tsx:1713-1754`.
- Simulated browser autofill: a `change` event on the hidden serialized input with either the serialized value ("2") or a derived label ("Bob") sets the selection and the input label `packages/react/src/combobox/items/createItems.test.tsx:1149-1174`.
- Anchors rendered via the item `render` prop change click semantics: `<a href>` clicks neither select nor close `packages/react/src/combobox/item/ComboboxItem.test.tsx:337-368`; `<a href="#hash">` clicks select nothing but close the popup `packages/react/src/combobox/item/ComboboxItem.test.tsx:370-396`; `<a>` without `href` behaves like a normal item (select + close) `packages/react/src/combobox/item/ComboboxItem.test.tsx:398-423`.
- `mousedown` on an item has `defaultPrevented === true` `packages/react/src/combobox/item/ComboboxItem.test.tsx:251-278`.

## Edge cases (rapid interactions, unmount, nesting)

- Duplicate derived values: the first occurrence always wins for label resolution regardless of lookup order ("First" over "Clone"), and a console error "Two items passed to createItems() derived the value N" is emitted for each duplicated value `packages/react/src/combobox/items/createItems.test.tsx:1645-1682`.
- Falsy primitive derived values (0, '', false) and `bigint` work end to end — label resolution, `aria-selected`, and hidden-input serialization `packages/react/src/combobox/items/createItems.test.tsx:1611-1643`.
- Null holes in source data never reach the accessors, reach the render callback while unfiltered, and are dropped as soon as filtering runs `packages/react/src/combobox/items/createItems.test.tsx:388-425`.
- A sentinel "empty selection" item is an ordinary item (defaultValue "none" → label "None") `packages/react/src/combobox/items/createItems.test.tsx:486-500`.
- Async data lifecycle: labels resolve and degrade as data loads and shrinks (`3` → `Carol` → `3`) `packages/react/src/combobox/items/createItems.test.tsx:553-577`, with raw-ID fallback when results are cleared `packages/react/src/combobox/items/createItems.test.tsx:338-386`.
- External windows (`filteredItems`): each root resolves against its own window even when the collection is shared — window items never leak into the collection `packages/react/src/combobox/items/createItems.test.tsx:1464-1493`; window items are projected into the derived value domain for flat `packages/react/src/combobox/items/createItems.test.tsx:1362-1393` and grouped data `packages/react/src/combobox/items/createItems.test.tsx:1976-1992`; emptied or initially empty windows reset on reopen (grouped selection shows all options again) `packages/react/src/combobox/items/createItems.test.tsx:1994-2023`.
- A selected item absent from known data stays visible through the external window and is labeled from it `packages/react/src/combobox/items/createItems.test.tsx:1326-1360`.
- `limit` stops filtering once reached — the filter is not consulted for further items `packages/react/src/combobox/items/createItems.test.tsx:1782-1812` — and drops emptied groups `packages/react/src/combobox/items/createItems.test.tsx:1968-1974`.
- Filtering is locale-aware (Turkish dotted-I: "i" matches "İzmir", not "Isparta") `packages/react/src/combobox/items/createItems.test.tsx:737-765`.
- Custom filters receive source items (all leaves, including grouped data) and may match fields that are neither value nor label (email) `packages/react/src/combobox/items/createItems.test.tsx:849-876`, `packages/react/src/combobox/items/createItems.test.tsx:910-951`, `packages/react/src/combobox/items/createItems.test.tsx:1955-1966`.
- Lazy normalization: accessors are not invoked at `createItems()` time for flat or grouped data `packages/react/src/combobox/items/createItems.test.tsx:1816-1835`; `getValue` runs only over leaf items `packages/react/src/combobox/items/createItems.test.tsx:1837-1868`, `packages/react/src/combobox/items/createItems.test.tsx:2025-2064`; `getLabel` runs only for values that need a label `packages/react/src/combobox/items/createItems.test.tsx:1870-1887`.
- Virtualization edge cases: a rendered window registers at its filtered indexes `packages/react/src/combobox/item/ComboboxItem.test.tsx:492-546`; items missing from the filtered values are not registered `packages/react/src/combobox/item/ComboboxItem.test.tsx:548-572`; explicit-index items select the correct filtered item after filtering `packages/react/src/combobox/item/ComboboxItem.test.tsx:575-613`.
- Performance guard: items that stay mounted across a keystroke that does not change filter membership do not re-render (stable `render` prop element lets `React.memo` bail) `packages/react/src/combobox/item/ComboboxItem.test.tsx:616-671`.
- SSR: `renderToString` resolves a `defaultValue` label from the external window ("Alice") `packages/react/src/combobox/items/createItems.test.tsx:1529-1541`.
- Custom `isItemEqualToValue` (case-insensitive) resolves selections from both collection data and external windows `packages/react/src/combobox/items/createItems.test.tsx:816-847`, `packages/react/src/combobox/items/createItems.test.tsx:1294-1324`.
- `itemToStringLabel` does not participate in filtering — filtering stays on collection-derived labels `packages/react/src/combobox/items/createItems.test.tsx:680-703`.
- Items whose only change is selection state remain mounted and update in place when the popup is kept mounted `packages/react/src/combobox/item-indicator/ComboboxItemIndicator.test.tsx:20-45`.
