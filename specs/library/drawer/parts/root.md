## State model (controlled/uncontrolled, defaults, transitions)

- Open: drawer is closed by default with no `open`/`defaultOpen` (`packages/react/src/drawer/root/DrawerRoot.test.tsx:680`). Uncontrolled `defaultOpen` mounts open and can be closed by interaction (swipe dismiss removes the popup) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1617-1638`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1666-1674`). Controlled `open` + `onOpenChange` is the standard pattern; `onOpenChange` receives the requested next state and a cancelable details object (`packages/react/src/drawer/root/DrawerRoot.test.tsx:36-55`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:343-352`).
- Controlled always-open (`open` literal `true`, parent never re-renders): a swipe past the dismiss threshold still calls `onOpenChange(false, details)` so the parent learns of the dismiss intent, but the drawer remains open; the controlled re-open/re-render settles within one animation frame (test must `waitSingleFrame` in `act` before asserting restored state) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1073-1111`).
- Close cancellation: `onOpenChange(nextOpen, details)` details expose `cancel()`; canceling a close keeps the drawer open with all transient swipe state cleared (`data-open` retained, no `data-swipe-dismiss`, `--drawer-swipe-movement-y` reset to `'0px'`) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1045-1071`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:339-365`). `cancel()` is selective by `details.reason` (tests cancel only `REASONS.swipe`) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:345-352`).
- Snap point: controlled via `snapPoint`/`onSnapPointChange` or uncontrolled via `defaultSnapPoint`; on close the active snap point resets to `defaultSnapPoint` when provided, otherwise to the first entry of `snapPoints` (`packages/react/src/drawer/root/DrawerRoot.test.tsx:822-832`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:834-846`). A canceled close does NOT reset the snap point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:863-873`).
- On an accepted swipe close of a controlled drawer, the snap point resets to the default (`'100px'`), not to the pre-swipe value (`'300px'`) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1113-1133`). When the parent rejects the dismissal, the snap point is restored and the popup returns to `data-open` after a frame (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1583-1611`).
- Imperative snap point control: context `setActiveSnapPoint(value)` routes through `onSnapPointChange`; `details.cancel()` blocks the change (active stays at the previous valid value) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:875-907`). Setting a value not present in `snapPoints` (e.g. `999`) still invokes `onSnapPointChange(999, {reason: REASONS.none})` but the active snap point falls back to the last valid value (`packages/react/src/drawer/root/DrawerRoot.test.tsx:898-906`).
- Nested swipe progress store: internal store (`subscribe`/`getSnapshot`, usable with `useSyncExternalStore`); `onNestedSwipeProgressChange(0.5)` updates it and notifies subscribers exactly once; setting the same value again does not notify; `NaN` is normalized to `0` and notifies (`packages/react/src/drawer/root/DrawerRoot.test.tsx:909-934`).
- Snap point resolution (from `useDrawerSnapPoints`, `modal={false}` open root, viewport `offsetHeight` 400, popup `offsetHeight` 300):
  - Every entry resolves to `{value, height, offset}` where `offset = popupHeight - height` (all seven data points in the units test fit this: `-1 → {height:0, offset:300}`, `'2rem' → {40, 260}`, `'100px' → {100, 200}`, `200.5 → {200.5, 99.5}`, `800 → {300, 0}`; `200 → {200, 100}` in the second test) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:79-86`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:102-104`).
  - String values support `px` and `rem` (`'2rem'` at a 20px root font size resolves to 40px) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:57-58`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:81-82`). UNVERIFIED — inferred from `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:81-82`, the exact resolution base of fractional values `0 < n <= 1` (e.g. `0.5`) is never asserted.
  - Numeric values resolve as raw pixel heights clamped to `[0, popupHeight]`: `-1 → 0`, `800 → 300` (popup height, not the 400px viewport) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:81-85`).
  - Invalid entries (`NaN`, `'invalid'`, `'invalidpx'`, `'invalidrem'`) are filtered out entirely; `-1` is kept but clamped (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:79-86`).
  - Duplicate heights keep the last occurrence: with both `200` and `200.5` in the list, only `200.5` appears, and an active `snapPoint` of `200` resolves to that kept entry's offset (99.5) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:75`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:84`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:88`). A single-entry list resolves without a dedup pass (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:123-131`).
  - `activeSnapPointOffset` is `null` when the list is empty, when `snapPoint` is `null`, or when `snapPoint` is invalid (e.g. `'invalid'`); with `null`/invalid active the popup's `--drawer-snap-point-offset` is `'0px'` (closed) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:106-113`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:116-121`). Otherwise the popup style carries `--drawer-snap-point-offset` equal to the active offset in px (e.g. `'99.5px'`) (`packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:89-91`).
- Swipe movement math (pure units): `getSnapPointSwipeMovement(currentOffset, movement)` returns the raw movement while the projected next offset stays `>= 0` (including exactly at the open edge, `nextOffset === 0`); once the drag would overshoot the open edge, the overshoot portion is damped with a square root — `getSnapPointSwipeMovement(0, -150)` ≈ `-Math.sqrt(150)` and `(100, -250)` ≈ `-Math.sqrt(150) - 100`; movement in the closing direction is never damped (`packages/react/src/drawer/root/useDrawerSnapPoints.test.ts:4-18`).
- `closestSnapPointIndex(values, target)` returns the index of the nearest value, keeps the first index on ties, and returns `-1` for an empty list (`packages/react/src/drawer/root/useDrawerSnapPoints.test.ts:20-29`).

- Composition used throughout: `Drawer.Root` > (`Drawer.Trigger`) + `Drawer.Portal` > (`Drawer.Backdrop`) + `Drawer.Viewport` > `Drawer.Popup` (>`Drawer.Close`); the Viewport is the gesture surface in swipe tests while `document.elementFromPoint` is mocked to hit-test the popup (`packages/react/src/drawer/root/DrawerRoot.test.tsx:48-53`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:295-305`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:148-161`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1052-1058`).
- Without `keepMounted`, a closed drawer's popup is removed from the DOM entirely (dismissal asserts `queryByTestId('popup')` is null) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1404`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1425`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1488`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1638`).
- With `Drawer.Portal keepMounted`, an accepted dismissal finishes with the popup present and `data-closed` set instead of unmounted (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1557-1581`).
- Detached (handle-linked) composition: `Drawer.Trigger`s and the `Drawer.Root` need not be adjacent; the root's render prop content only mounts when open (`packages/react/src/drawer/root/DrawerRoot.test.tsx:613-653`).
- Data attributes observed on parts: popup `data-open`, `data-closed`, `data-swipe-dismiss` (transient dismissal marker), `data-ending-style`; backdrop `data-swipe-dismiss` and `data-swiping` (transient swipe marker) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1062-1066`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1103-1106`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1577`).
- CSS custom properties on the popup: `--drawer-swipe-movement-y` (live drag offset, e.g. ≈ `-Math.sqrt(150)` px during overshoot; reset to `'0px'` after a canceled swipe) and `--drawer-snap-point-offset` (active snap offset in px, `'0px'` when closed/null) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1067`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1155`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1221-1223`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:89-91`, `packages/react/src/drawer/root/DrawerSnapPoints.test.tsx:108-110`).
- During damped overshoot the popup receives NO inline `transform` (`style.transform === ''`); movement is expressed through the CSS variable (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1220`).

## Events (names, payload shape, bubbling, preventDefault semantics)

- `onOpenChange(open: boolean, details: Drawer.Root.ChangeEventDetails)`:
  - `details.reason` observed values (symbolic constants from `internals/reasons`, literals not asserted in these tests): `REASONS.swipe` (swipe dismiss) and `REASONS.closeWatcher` (CloseWatcher close event) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:345-352`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1688-1690`).
  - `details.cancel()` prevents the close; after a canceled swipe close the transient styles are cleared and swipe offsets/snap point restored (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1045-1071`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1135-1160`).
  - Swipe dismiss intent on a controlled always-open drawer still fires `onOpenChange(false, details)` — notification happens even when the parent will not act (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1092-1094`).
  - No bubbling/preventDefault semantics are asserted for this callback in these files.
- `onSnapPointChange(snapPoint: Drawer.Root.SnapPoint | null, details: Drawer.Root.SnapPointChangeEventDetails)`:
  - Fires when the drawer closes via close press with `details.reason === REASONS.closePress` (the reset-to-default transition) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:848-861`).
  - Fires for programmatic `setActiveSnapPoint` with `details.reason === REASONS.none`, including for invalid values (`999`) even though the active value falls back (`packages/react/src/drawer/root/DrawerRoot.test.tsx:898-906`).
  - `details.cancel()` blocks the snap point change (requesting `'100px'` while at `'300px'` with cancel leaves `'300px'`) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:875-899`).
- Nested swipe progress notifications: store subscribers are notified once per distinct value change, not for duplicate sets; `NaN` is normalized to `0` and notifies once (`packages/react/src/drawer/root/DrawerRoot.test.tsx:909-934`).
- Handle commands (`handle.open`/`close`/`openWithPayload`) drive the same open state and aria wiring as trigger clicks (`packages/react/src/drawer/root/DrawerRoot.test.tsx:682-706`).

## Edge cases (rapid interactions, unmount, nesting)

- Duplicate CloseWatcher `close` events dispatched synchronously produce exactly ONE `onOpenChange` call (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1681-1687`).
- Root unmount with a live handle: `handle.isOpen` becomes `false`; calling `open`/`openWithPayload`/`close` on a handle with no mounted root emits one console warning each containing "no root using this handle is mounted" (3 calls → 3 warnings) and does not open (`packages/react/src/drawer/root/DrawerRoot.test.tsx:763-778`).
- Remount of a handle-backed root attaches fresh state: payload is not retained (`'No payload'`), drawer stays closed, trigger aria is reset; a subsequent trigger click works normally with fresh payload and aria-controls (`packages/react/src/drawer/root/DrawerRoot.test.tsx:780-796`).
- Calling multiple handle methods (`openWithPayload(8)`, `open('trigger')`, `close()`) synchronously while detached is safe (only warnings) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:768-770`).
- Swipe geometry/velocity edge cases (all `it.skipIf(isJSDOM)` — Chromium-only):
  - Dismiss threshold is size-based, not fixed px: a 90px swipe on a 200px popup (45%) does not dismiss; 120px (60%) does. UNVERIFIED — inferred from `packages/react/src/drawer/root/DrawerRoot.test.tsx:576-611`, the exact threshold fraction between 45% and 60% is never asserted.
  - Low-velocity swipes near a snap point keep the drawer open and the current snap point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1284-1309`).
  - If the release velocity reverses direction late in the gesture, the drawer does not dismiss (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1311-1345`).
  - Sub-threshold slow drags keep the current snap point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1515-1534`); a slow long drag on a plain drawer does close it (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1613-1642`).
  - Overshoot past the fully-open edge is sqrt-damped, and only after the swipe direction is established (a zero-distance move precedes the measured moves) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1162-1228`).
- `snapToSequentialPoints` semantics (Chromium-only): a long fast drag skips intermediate snap points (`'100px'` → `'1'`) (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1230-1255`); a small fast flick advances exactly one point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1257-1282`); a slow drag lands on the nearest sequential point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1347-1366`); from the last point, a small drag advances toward dismissal (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1368-1387`); a fast flick toward "more open" from the first/last point keeps it (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1494-1513`); dragging past the final point dismisses (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1389-1408`).
- Without `snapToSequentialPoints`, release resolves to the closest snap point including "closed" — ending closer to closed dismisses even from a mid-list snap point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1536-1555`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1410-1429`).
- `swipeDirection="up"`: an upward flick dismisses from an upward-anchored snap point (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1431-1450`).
- Controlled `snapPoint={null}`: an upward drag opens/snaps to the full point (`'1'`); a downward drag dismisses (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1452-1492`).
- Controlled acceptance/rejection timing: after an accepted swipe dismissal of a keepMounted drawer, `data-closed` only holds after one animation frame (`waitSingleFrame` in `act`); likewise a rejected dismissal restores `data-open` + snap point after a frame (`packages/react/src/drawer/root/DrawerRoot.test.tsx:1573-1577`, `packages/react/src/drawer/root/DrawerRoot.test.tsx:1601-1606`).
- Nesting: a nested `Drawer.Root`'s swipe progress propagates to the outer root's `nestedSwipeProgressStore` (outer probe/subscriber observe the nested control's value) with once-only and NaN-normalization semantics (`packages/react/src/drawer/root/DrawerRoot.test.tsx:909-934`).
- Missing context guard: calling `useDrawerRootContext()` outside `Drawer.Root` throws `Base UI: DrawerRootContext is missing. Drawer parts must be placed within <Drawer.Root>.` (`packages/react/src/drawer/root/DrawerRoot.test.tsx:936-946`).
- Strict Mode and React 17 compatibility: root registration with a `Drawer.Provider` (and `data-active` on `IndentBackground`) happens before mount passive effects flush for controlled `open`, for `defaultOpen` under `React.StrictMode`, and when `useId` returns `undefined` (React 17 id fallback); unregistration via `removeDrawer` happens before the teardown passive effect (`packages/react/src/drawer/root/DrawerRoot.test.tsx:948-1043`).
