## Discrepancies (docs page vs. behavior.md)

No direct contradictions found between the page prose and
`specs/library/direction-provider/behavior.md`. Items flagged for lack of coverage or notation:

- Docs-only claim stated as fact: "`<DirectionProvider>` ... does not affect HTML and CSS"
  (`docs/src/app/(docs)/react/utils/direction-provider/page.mdx:26`). behavior.md "Accessibility
  (roles, aria-*, id linking)" marks UNVERIFIED whether the provider renders a DOM element or sets
  a `dir` attribute — no test asserts either way. Not contradicted by tests, but unverified by
  them.
- Docs-only claim: the requirement that applications set `dir="rtl"` (HTML) or `direction: rtl`
  (CSS) themselves (`docs/src/app/(docs)/react/utils/direction-provider/page.mdx:26`). No test
  counterpart exists in behavior.md.
- Docs-only claim: `useDirection`'s stated purpose for portaled components rendered outside the
  application root (`docs/src/app/(docs)/react/utils/direction-provider/page.mdx:42`). behavior.md
  "DOM structure & portal behavior" records that no portal behavior is tested.
- Import-path notation mismatch: the Anatomy snippet documents
  `@base-ui/react/direction-provider` (`docs/src/app/(docs)/react/utils/direction-provider/page.mdx:18`),
  while behavior.md "Public API surface (props, parts, subcomponents)" records the test suite
  importing from `@base_ui/react/direction-provider` (underscore). The package's real name is
  `@base-ui/react` (`packages/react/package.json:2`), so the docs page matches reality; the
  behavior.md spelling appears to be a transcription artifact, not a genuine API conflict.
- Omission (behavior.md fact not surfaced on the page): behavior.md "State model
  (controlled/uncontrolled, defaults, transitions)" and "Edge cases (rapid interactions, unmount,
  nesting)" record that updating the `direction` prop (`'rtl'` → `'ltr'`) propagates to
  descendants live without remounting, and that nested providers/unmount behavior are untested;
  the page never mentions dynamic direction switching or nesting multiple providers.
  Informational, not a contradiction.
